## 📊 Content Delivered

### 8 Embedded Systems Courses
```
1. C Programming for Embedded Systems (Beginner)
   → Microcontrollers, Memory, ISR, Peripherals
   
2. ARM Cortex-M Architecture (Intermediate)
   → ARM Processors, CMSIS, Power, Debugging
   
3. RTOS Fundamentals (Intermediate)
   → FreeRTOS, Task Scheduling, Communication
   
4. Embedded Linux (Advanced)
   → Yocto, Device Drivers, Kernel Modules
   
5. Communication Protocols (Advanced)
   → CAN, Ethernet, Wireless, Industrial
   
6. Debugging & Testing (Intermediate)
   → JTAG, Unit Testing, Hardware-in-loop
   
7. Low Power Design (Advanced)
   → Power Optimization, Sleep, Voltage Scaling
   
8. Security in Embedded Systems (Advanced)
   → Secure Boot, Cryptography, Firmware Updates
```

### 10 Coding Problems
```
Easy (3):
  1. Bit Manipulation - Set/Clear/Toggle Bits
  2. Check if Number is Power of 2
  3. Pointer Arithmetic - Array Access

Medium (4):
  4. Circular Buffer Implementation
  5. ISR - Button Press
  8. CRC Calculation
  9. GPIO LED Control

Hard (3):
  6. Memory Pool Allocator
  7. RTOS Task Synchronization
  10. Race Condition Detection
```
